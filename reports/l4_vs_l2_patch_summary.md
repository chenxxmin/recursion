# L4 vs L2 组件分析（flip hunt）对比 — 结果汇总

**日期**：2026-08-28
**前置**：`multi_pos_patch_summary.md`（l1/l2 的翻转通道定位）。
本文档把同一 pipeline 推进到 **4 层模型**，并与**同族 2 层模型**做受控对比。

## 1. 设置

- 模型族：`mixed_basic_scale_matrix_rules12`，d256 r8 h4，P127，规则对
  **[(1,1),(2,3)]**，`use_ab_tag=false`，N=2。同族同 seed（17996/18318/
  34789/44536）的 l2 与 l4 成对比较——宽度、头数、规则对、seed 全部匹配，
  只有深度不同（比跨族对照旧报告更干净）。
- 训练 accuracy：l4 全部 ≥99.5%；l2 96.7~99.2%（非满分，但 probe 分布上
  baseline 足够高，见下）。
- pipeline：`src/multi_pos_patch.py`，`--pairs 128 --len 12 --max-k 9`，
  与既往 flip hunt 参数一致。
- **baseline  sanity（probe 分布，own-rule match）**：l2 0.974~0.999、
  l4 0.993~1.000，双方向 neither ≈ 0。环境/加载正常。
- 注意 rules23 规则对下 **x3 已分叉**（x3^A=x1+x2，x3^B=2x1+3x2），
  因此 q≥2 位置的 hidden state 本身就携带规则证据；lag2 头的 k3/k4
  结构性零值不变（它读的 x1/x2 仍共享）。

## 2. L4 主要发现

### 2.1 规则证据通道：顶部两层的**整层 attention 输出**，单头无效

| seed | 方向 | 最强条件 | mean Δflip | per-k 范围 |
|---|---|---|---|---|
| 17996 | AtoB | attn_all_l3@q | +0.142 | 0.06~0.19 |
| 18318 | AtoB | attn_all_l3@q | +0.165 | 0.13~0.20 |
| 34789 | AtoB | attn_all_l3@q | +0.190 | 0.13~0.26 |
| 44536 | AtoB | attn_all_l3@q | +0.326 | 0.28~0.38 |
| 17996 | BtoA | attn_all_l2@q | +0.222 | 0.11~0.33 |
| 18318 | BtoA | attn_all_l2@q | +0.334 | 0.20~0.40 |
| 34789 | BtoA | （全部 ≤ +0.023） | — | — |
| 44536 | BtoA | attn_l3h1@q（单头，弱） | +0.061 | 0.04~0.09 |

- **单头 patch 在 L4 几乎完全失去翻转能力**：全部 8 个 模型×方向 中，
  单头 mean Δflip 最高仅 +0.061（per-k 最高 0.133），而整层 attention
  （`attn_all@q` = 替换该层全部头的 c_proj 输入）可达 mean +0.33 /
  per-k 0.40。证据**分散在同一层的多个头里**，不存在单头开关。
- 整层 patch 的 match_src ≈ 0.01~0.06、hyb ≈ 0：**是真规则翻转**，
  不是状态转移或杂交自洽计算。
- **方向×层特化（4/4 seed 一致的结构）**：AtoB 的翻转通道在 **layer 3**；
  BtoA 的翻转通道在 **layer 2**（2/4 seed 强、2/4 seed 几乎无可翻转位点）。
  层与方向的绑定关系跨 seed 稳定，头编号才随 seed 置换（此前 l1/l2 的
  规律是"角色不变、编号置换"，这里升级为"层×方向角色不变"）。

### 2.2 MLP 首次进入证据通道：mlp_l2@q

- s34789/s44536 AtoB k=3：Δflip **+0.20/+0.27**（hyb≈0、src≈0，真翻转）；
  s17996 BtoA k=3：+0.086。k>3 时迅速衰减到 ≤0.05。
- 对比：mlp_l0/l1@q patch → 崩坏（neither ≈ 0.98~1.0，浅层 MLP 仍是
  递推负载组件）；mlp_l3@q → 状态转移（src ≈ 0.995）。
- 即 L4 中 layer 2 的 MLP 在最早的可判别位置（k=3，q=x3 位置）参与
  规则判定——l1/l2 模型中从未观察到 MLP 翻转。

### 2.3 角色分层（8 个 模型×方向 平均）

| patch 对象 | 后果 | 与 l1/l2 的关系 |
|---|---|---|
| mlp_l0/l1@q | 崩坏（nei≈0.99） | 不变：浅层 MLP 负载 |
| attn_all_l0/l1@q | 基本无效（Δ≤+0.015） | 浅层 attention 无证据 |
| **attn_all_l2/l3@q** | **规则翻转（见 2.1）** | L4 特有：证据在顶部两层 |
| **mlp_l2@q** | **k=3 部分翻转** | L4 特有 |
| mlp_l3@q、resid3@q/W、emb@W | 状态转移（src≈1.0） | 不变：末层/整向量天花板 |
| resid_i@q | src 随深度递增：0.42→0.62→0.96→1.00 | 见 3.2 |

## 3. L2 结果（同族对照）与 L4 对比

### 3.1 L2：单头即可翻转，头在 layer 0 或 layer 1

8 个 模型×方向 中 6 个存在明显单头翻转通道（mean +0.03~+0.15，
per-k 最高 0.23）：layer 0（5/8：s17996-AtoB l0h1、s18318 双向 l0h1、
s44536 双向 l0h0）或 layer 1（3/8：s17996-BtoA l1h1、s34789 双向
l1h1/l1h3）。两种解剖都存在，layer 分布随 seed。

- layer 0 证据头 k3/k4 **严格为零**（lag2 头读共享的 x1/x2，patch 是
  恒等操作）——旧结构性边界在 rules23 下不变；
- layer 1 证据头**所有 k 都可翻转**（含 k=3：layer 1 能读到 layer 0 已
  编码的分叉 x3）——深度带来"更早可判别"的证据。

### 3.2 L4 vs L2 对比结论

1. **证据通道随深度上移且分散**：l1 单一 lag2 头 → l2 单个头（l0 或
   l1）→ **l4 顶部两层、跨头分布 + layer-2 MLP**。深度每增加，"单组件
   开关"进一步瓦解：l4 单头 patch 上限（mean 0.06）只有整层 patch
   （0.33）的 1/5。与旧报告 B5（h4 翻转率低于 h2，疑证据稀释）一致并
   推进了一层：稀释在深度维度上继续加剧。
2. **方向不对称在 L4 结构化**：l1/l2 中方向不对称幅度随 seed/规则对
   不定（B2）；l4 中不对称表现为稳定的**层×方向分工**（AtoB→l3，
   BtoA→l2），且有 2/4 seed 的 BtoA 几乎无可翻转位点（单向不可patch性）。
3. **MLP 的角色出现深度分化**：浅层 MLP 永远是递推负载（patch→崩坏），
   末层 MLP 是状态载体（patch→状态转移），**只有 l4 的中间层（l2）
   MLP 参与规则证据**——深层模型把规则判定做成了跨组件（attention+
   MLP）的层内并联计算。
4. **浅层表示被后续层重算的程度随深度增加**：resid0@q 的状态转移率
   l2 为 0.82，l4 仅 0.42（l4 的 resid1@q 0.62、resid2@q 0.96）。
   层数越多，早期层的 patch 越容易被上层"纠正"——这也解释了为什么
   l4 的证据必须到顶部两层去 patch 才有效。
5. **不变量**：① patch 后果按通道角色分层（操作数/浅层→崩坏，证据→
   翻转，末层/整向量→状态转移）在所有深度成立；② lag2 型证据头的
   k3/k4 结构性零值成立；③ attention pattern 与规则无关（日志中
   attention overview 逐 head 的 lag 分布在 A/B 间一致）。

## 4. 未解决问题

- **C1 BtoA 在 l2/l4 的分工为何不对称**：AtoB→l3、BtoA→l2 的绑定机制
  不明；s34789/s44536 的 BtoA 无可翻转位点是否意味着规则 B 的证据在
  这些 seed 中完全纠缠进操作数通道（类似 l1 seed18318 反例）？
- **C2 l4 的整层翻转是否可再分解**：attn_all@q 翻转但单头不翻转，
  可能是"证据向量 = 多头输出之和，单头分量不足以越过判定盆地边界"
  （与 B3 的模 p 比值判定+盆地命中率框架兼容）。可用证据值扫描
  （合成 V 投影）在 l4 上复测判定函数是否仍是 ĉ2 的尖锐函数。
- **C3 mlp_l2 的 k=3 特化**：为何只在最早判别位置参与？是否与"x3 是
  首个分叉 token，需要专门的一次性规则判定电路"有关？
