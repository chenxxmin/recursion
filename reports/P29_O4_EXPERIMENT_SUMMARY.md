# P=29 order=4 实验结果汇总（系数难度 / 曝光率 / 容量线）

> 整理时间：2026-10-19。数据：`/data/cxm/recursion/coef_size/`（失败批次的结果文件已于 2026-10-14 清理，表中数据来自清理前的汇总记录）。
> 共同设置：`TASK=single`、`ORDER=4`、P=29、TRAIN_LEN=16、NUM_MASK=3、seed=17996、LR=3e-4 cosine、WD=1、bs=512、fp32。基准模型 d512l2r8h4（10.5M）。
> 六组固定系数（canonical）：(1,4,18,24) (1,4,19,16) (1,7,2,25) (1,7,17,1) (1,8,4,13) (1,9,17,1)。

## 1. 主线结果矩阵

| 数据制度 | 模型 | 预算 | 结果（best test acc） |
|---|---|---|---|
| **70% 静态切分**（495k train） | d512l2 | ~2600ep（多轮续跑） | **3/6 在学：(1,7,2,25) 92.9%、(1,7,17,1) 91.7%、(1,8,4,13) 78.8%**；另 3 组 500ep 纯随机（3.3%） |
| 42% 抽样+每轮鲜测（300k） | d512l2 | 500ep | 全灭 ≤4.1%（(1,8,4,13) 卡在 11.5% 一位置平台） |
| 80% | d512l2 | ~360ep（2h） | 全灭 ≤3.4%（(1,8,4,13) 11.5% 平台） |
| 90% | d512l2 | ~320ep（2h） | 全灭，**连 (1,7,17,1) 都贴在 3.4% 且 train 不起** |
| 90% + LR 退火匹配（EPOCHS=800） | d512l2 | 800ep 全程 | 全灭；LR 退火到 0 无济于事，PreClipNorm ~0.03 → "LR 不退火"假说证伪，模型掉入均匀预测死盆地 |
| 70% | **d1024l2** | 640~1000ep | 2 个跑满 1000ep 纯随机；最好 (1,8,4,13) 60.9%（后回落） |
| 70% | **d512l4** | ~220ep（2h） | 全灭 ≤3.3%（l2 同期的易学组也趴） |
| **90%** | **d64l2（0.17M）** | 在跑，已到 ep2000 | **在学！best 49.7%（@1820），train/test 40% 爬升中** — d512 版同配置 800ep 全程死平 |
| 70% 复现性检查（重启后） | d512l2 | 200ep | 与原版**逐位一致**（ep80 起跳 46.0%），环境/驱动升级无影响 |

## 2. 结论

1. **系数结构（而非大小）决定 o4 可学性**：P23 下同 seed 固定系数 4/6 满分（≤340ep）；P29 下同一批系数只有 3 组可学，且 (1,8,4,13) 有标志性的"11.5% 一位置平台"。
2. **P29 显著难于 P23**：同系数同 seed 下 P23 满分 vs P29 需要 ~2600ep 才到 92.9% 且未收敛。
3. **低曝光+鲜测（42%）是死路**，与 P127-300k（0.115% 曝光）失败同一条主线。
4. **高曝光（80/90%）下大模型坍缩**：d512 连 train 都起不来（均匀盆地），而 **d64 小模型在 e90 反而能学**——容量在高曝光下是负担不是资源（与 d1024/l4 更差一致）。
5. 当前最优配方：70% 静态切分 + d512l2 + 长时间；e90 攻关方向转向小模型。
