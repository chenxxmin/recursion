# fill_blank 实验总览：训练模型"填空白"

> 生成时间：2026-10-14。本文用仓库实际代码（`RecurrenceDataset` + `make_fill_blank_collate`，
> 与在跑实验同 seed）重建数据并抽样，展示的就是模型真实看到的样本。
> 对应批次：`fill_blank_single_o1_d512l2_P1009_tr16`（GPU 3）。
> 姊妹任务：corrupt_fix（污损成随机错误值、要答位置+值，见 `reports/CORRUPT_FIX_EXPERIMENT_OVERVIEW.md`）。

## 0. 任务一句话

给模型一条**恰好有一个位置被抹成空白**的模运算递推数列，让它**填出空白处的正确值**
（空白自己标出了位置，所以不用答位置，输出只有一个 token）。

## 1. 序列与监督格式

窗口长度 N=16，完整监督序列：

```
[ x0, x1, ..., x15 , EOS , true_value ]
  └─ 含一个空白的数列 ──┘   ↑         ↑
                       结尾标记   输出:正确值（仅作标签，不进输入）
```

- **模型输入** = 前 17 个 token（含空白的数列 + EOS）；`true_value` 只是标签
  （next-token 移位：EOS 槽的隐状态预测它）。
- **计算 loss/acc 的位置只有 1 个**：EOS 槽（target[16]）。数列部分的预测全部被
  loss_mask 屏蔽。
- **词表布局**：值 token `0..1008`；空白 token `□ = 1009`（复用现有 missing token id）；
  EOS = 1010。词表大小 = **1011**。
- **污损机制**（在线，collate 内逐 batch 新鲜随机，train/test 同样）：恰好一个位置 k
  均匀选自 `[0, 16)`（**含初始值位置**），替换为空白 token。同一条干净样本每个 epoch
  的空白位置都不同。
- **可解性**：只有一处空白，其余位置干净，正确值可由邻位经递推公式正推/反推得到
  （c=746 是 mod 1009 的原根，任意位置都可推断）。

## 2. 本批实验：order=1 等比递推，P=1009

**递推公式**：`x_k = 746 · x_{k-1} mod 1009`（框架无常数项，order=1 是**等比**数列，
不是等差）。746 是 mod 1009 的原根（乘性阶 1008），窗口不会出现短循环退化。

**样本量**：order=1 初始状态只有 1 个值，状态空间 = P = 1009；`full_split` 按 70%-30% 切分 →
**训练 706 条 / 静态测试 303 条**（每条 = 一个初始值 roll 出的 16 项窗口）。

## 3. 模型与训练设置

| 项 | 值 |
|---|---|
| 模型 | FibonacciTransformer（decoder-only，RoPE）：d_model=512，2 层，1 头，MLP 比 8，dropout 0 |
| 优化 | AdamW lr=3e-4，weight_decay=1，grad clip 1.0，batch 512，cosine 调度 T_max=6000 epoch |
| 精度 | fp32 + TF32（写死）；seed=42 |
| 评估 | 每 epoch 评估一次；早停 = 静态测试 acc ≥ 0.99（另有不提升 3000 epoch 兜底） |
| 指标 | acc = EOS 槽（值）的 token 级准确率，即"填对空白的比例" |
