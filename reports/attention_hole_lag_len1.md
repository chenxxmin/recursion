# misslen=1 模型的 attention 空缺-lag 分解

> 日期：2026-09-02。任务格式：`[x1, x2, f3, x3, f4, x4, ...]`，规则二阶
> `x_j = a·x_{j-1} + b·x_{j-2} (mod 127)`，`(a,b) ∈ {(1,1),(2,3)}`，flag f_j 指示当步规则。
> 污损：value 位置以 0.1 概率被替换为 missing token（段长 1，段后一位强制干净）。
>
> **三类定义**（对每个被预测的 value x_j，query 位于持有 f_j 的位置）：
> - **lag0**：x_j 本身是洞（填洞）
> - **lag1**：x_{j-1} 是洞（洞后第一位，需先重构洞值再套规则 = 两跳推理）
> - **clean**：x_j 与 x_{j-1} 都齐全
>
> 探针脚本：`scripts/probe_attention_hole_lag.py`（测试集 500 条，OOD 长度 128，
> 与训练评估同分布）。原始输出：`logs/probe_hole_lag_l1.log`、`logs/probe_hole_lag_l2.log`。

### 机理推测

- **头按 lag 分工**：h2 主读 x_{j-1}、h0 主读 x_{j-2}、h1 主读 x_{j-3}——正好是二阶规则
  （自身 + 两跳重构）所需的全套输入。
- lag0（填洞）时两个前驱都在，直接套规则 → 近乎满分（99.95%）。
- lag1 时 h2 把注意力大幅转向**洞位本身**（4%→29%）：洞位不携带数值，但带着位置编码，
  且紧邻洞的 flag f_{j-1} 指示"洞值是用哪条规则生成的"——模型在读重构所需的规则上下文。
- **瓶颈在 lag1 的两跳推理**（89.8%）：先 `x_{j-1} = a_{j-1}·x_{j-2} + b_{j-1}·x_{j-3}`，
  再 `x_j = a_j·x_{j-1} + b_j·x_{j-2}`。整体 99.06% 的失分几乎全来自这一类。

### 机理推测

- 第一层 h0 在 lag1 时把 **80% 质量压到洞位**（clean 时 57.8% 在 x_{j-1}）——比 l1 模型的
  同类转移更极端，像在显式标记"这里缺了一个值，需要重构"。
- h1（x_{j-2}）与 h2（x_{j-3}）提供重构洞值的两个输入，h3 读 flags（规则识别）。
- 两层模型的 lag0 略低于 l1（99.0 vs 99.95）但 lag1 略高（90.3 vs 89.8）——
  第二层对两跳推理略有帮助，但不本质。

## 综合结论

1. **填洞（lag0）是已解决的问题**（≥99%）；**洞后一位（lag1）是 misslen=1 的全部瓶颈**（~90%）。
2. lag1 的本质是**两跳组合推理**：重构洞值 → 套当步规则。attention 证据支持模型确实在这么做
   （读 x_{j-2}/x_{j-3} + 洞位/flag）。
3. 这与 len2 探针结果（`probe_two_miss_positions.py`：第 2 空 91.1%，且第 1 空错则第 2 空必错）
   同构——**len2 的第 2 空 ≈ 连续做两次两跳推理**。整条 misslen 线的核心难点就是
   "跨缺口的链式重构"，而不是记忆或单步规则应用。
