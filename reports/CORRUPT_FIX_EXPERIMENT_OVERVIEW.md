# corrupt_fix 实验总览：训练模型"找错并改正"

> 生成时间：2026-10-14。本文用仓库实际代码（`RecurrenceDataset` + `make_corrupt_fix_collate`，
> 与在跑实验同 seed）重建数据并抽样，展示的就是模型真实看到的样本。
> 对应批次：`corrupt_fix_single_o2_4coef_d512l2_P127_tr16`（order=2，GPU 4-7）、
> `corrupt_fix_single_o1_d512l2_P1009_tr16`（order=1，GPU 3）。

## 0. 任务一句话

给模型一条**恰好被改错了一个位置**的模运算递推数列，让它指出**错误发生在哪个位置**、
并给出**该位置的正确值**。

## 1. 序列与监督格式（两个批次共用）

以窗口长度 N=16 为例，模型的完整监督序列是：

```
[ x0, x1, ..., x15 , EOS , pos_k , true_value ]
  └─ 污损后的数列 ──┘   ↑      ↑         ↑
                   结尾标记  输出1:位置  输出2:正确值
```

- **模型输入** = 前 18 个 token（污损数列 + EOS + pos_k）；`true_value` 不进输入，只作标签
  （next-token 移位 + teacher forcing：值预测以位置为条件）。
- **计算 loss/acc 的位置只有 2 个**：EOS 槽（目标是位置 token `pos_k`）和 pos 槽（目标是正确值）。
  数列部分的 next-token 预测全部被 loss_mask 屏蔽。
- **词表布局**（互不重叠的 id 段）：值 token `0..P-1`；`P` = missing（本任务不使用，布局保留）；
  `P+1` = EOS；`P+2+k` = 位置 token `pos_k`。词表大小 = `P + 2 + 16`。
- **污损机制**（在线，collate 内逐 batch 新鲜随机，train/test 同样）：
  恰好一个位置 k 均匀选自 `[0, 16)`（**含初始值位置**），其值替换为 `[0, P) \ {原值}`
  中均匀随机的一个**错误值**（是真的错值，不是特殊的 missing 标记）。
  同一条干净样本每个 epoch 的污损位置和错值都不同。
- **正确性可解性**：只有一处错误，其余位置干净，正确值可由邻位经递推公式正推/反推得到
  （本批所有系数 b≠0 / c 为原根，所有位置都可推断）。

## 2. order=2 批次：P=127，四组随机系数

**递推公式**（x_k = a·x_{k-1} + b·x_{k-2} mod 127，四组并行实验，每组一张卡）：

| 实验名 | a | b |
|---|---|---|
| single_o2_corruptfix_a93b69_... | 93 | 69 |
| single_o2_corruptfix_a22b86_... | 22 | 86 |
| single_o2_corruptfix_a98b19_... | 98 | 19 |
| single_o2_corruptfix_a103b61_... | 103 | 61 |

## 3. order=1 实验：P=1009，等比递推

**递推公式**：`x_k = 746 · x_{k-1} mod 1009`（注意：框架无常数项，order=1 是**等比**数列，
不是等差）。746 是 mod 1009 的原根（乘性阶 1008），窗口不会出现短循环退化。

## 4. 模型与训练设置（两个批次相同）

| 项 | 值 |
|---|---|
| 模型 | FibonacciTransformer（decoder-only，RoPE）：d_model=512，2 层，1 头，MLP 比 8，dropout 0 |
| 优化 | AdamW lr=3e-4，weight_decay=1，grad clip 1.0，batch 512，cosine 调度 T_max=6000 epoch |
| 精度 | fp32 + TF32（写死）；seed=42 |
| 评估 | 每 epoch 评估一次；早停 = 静态测试 acc ≥ 0.99（另有不提升 3000 epoch 兜底） |
| 指标 | overall acc = 两个输出位的 token 级平均；per-position 分项给出**位置 acc**（target[16]）与**值 acc**（target[17]） |

## 5. 结果口径与路径

- 结果口径 = 训练日志 best test acc（污损是任务本体，无 clean/total 之分）。
- 日志：`/data/cxm/recursion/<批次名>/logs/`；checkpoint：`/data/cxm/models/<批次名>/`
  （`_best.pth` 纯权重、`_latest.pth` 滚动完整状态）。
- 已知小瑕疵：正常完成后追加的 attention 分析不认识 corrupt_fix 布局，会以 warning 跳过，不影响结果。
