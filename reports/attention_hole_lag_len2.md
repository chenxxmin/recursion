# misslen=2 最佳模型的 attention 四模式分解

> 日期：2026-09-02。任务格式与三分类定义同 `attention_hole_lag_len1.md`。
> 污损段长 1~2（保证每条样本至少有一段长度 2）。
>
> **四类模式**（对每个被预测的 value x_j，query 位于持有 flag f_j 的位置）：
> - **hole1**：x_j 是洞且 x_{j-1} 干净（单空，或连二空的第一空）
> - **hole2**：x_j 是洞且 x_{j-1} 也是洞（连二空的第二空）
> - **lag1**：x_j 干净但 x_{j-1} 是洞（洞后一位）
> - **clean**：都干净
>
> 注意：`x_{j-1}` 组与"洞位"组在 hole2/lag1 类别下会重复计入同一位置（两个观察视角），
> 因此这两类的行内占比之和可超过 100%。
>
> 探针：`scripts/probe_attention_hole_lag_len2.py`；原始输出：`logs/probe_hole_lag_len2.log`。

### 机理推测

- **Layer 0 的头按 lag 分工**：h1 主读 x_{j-1}、h2 主读 x_{j-2}、h3 主读 x_{j-3}（二阶规则 +
  重构所需的全套输入）；这套分工在四类下保持稳定，变的是**权重偏移**：
  - hole2 时 h2 对 x_{j-2} 从 42% → 62%（x_{j-1} 是洞，重心压向可用的最近真值）
  - lag1 时 h3 对 x_{j-3} 从 51% → 62%，且 h2/h3 都向洞位倾斜——
    lag1 时洞值可能需要两级重构（洞若是连二空的第二空，则 x_{j-2} 也缺），
    模型在读更深的历史 + 洞位的规则上下文
- **Layer 1 呈"双模式"**：hole1/clean 时 h0/h1 把 38~47% 压在 self（当前 flag 位）——
  直接套规则的工作模式；hole2/lag1 时集体转向洞位 + flags + x_{j-2}——重构模式。
- 这解释了正确率格局：clean ≈ hole1（98.4%，单跳足够）；hole2（91.4%，先推断前一洞值再算）；
  **lag1 最差（75.8%）——洞后第一位既要重构洞值、又要立即用它做下一步推理，
  且洞可能是双空之一（需两级重构），错误复合最集中**。
- 与 len1 模型对照（`attention_hole_lag_len1.md`）：len1 的 lag1 是 89.8%，len2 降到 75.8%，
  差距正是"洞是单空还是双空"的不确定性带来的。整条 misslen 线的瓶颈收敛于同一处：
  **跨缺口的链式重构**。
