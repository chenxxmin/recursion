# 证据值扫描实验：规则判定函数的完整测绘

**日期**：2026-08-26
**工具**：`src/evidence_sweep.py`（合成 V 内容 patch）
**图**：`reports/b3_sweep_fig.png`
**相关**：`reports/multi_pos_patch_summary.md`（B3 节）

## 1. 问题

HSS/翻转猎手实验发现：patch lag2 证据头能翻转规则，但只有 ~40%（天花板
~0.65）。这引出 B3 问题：**翻转率封顶是判定能力的上限，还是自然 patch
的证据值"说服力"不足？** 回答它需要把"证据值 → 模型决策"的完整函数
测出来，而自然 patch 每个样本对只给一个碰巧的证据值——必须合成。

## 2. 方法：合成证据值扫描

patch 点是 lag2 头在 query 位置 q 的 c_proj 输入切片（语义 = "该头读到的
token 的 V 内容"）。用模型自身权重直接合成任意证据 token x̂ 的 V 内容：

```
v(x̂) = c_attn(ln_1(wte(x̂)))[V 段、该头切片]     # x̂ ∈ 0..126 全部预算
```

不经过任何真实序列的前向。固定输入序列（规则 A 的历史），对每个 x̂ 做一次
前向，记录预测归属（规则 A 续写 / 规则 B 续写 / 其他）。

**保真性锚点**（每次使用必先核对）：
- x̂ = 真实证据值 → 行为与不 patch 一致（翻转 ≈ 0.008 ≈ baseline）；
- x̂ = 对方运行的真实证据值 → 复现自然 patch 翻转率（0.381 vs 0.38）。

## 3. 核心结果：判定函数的形状

横轴取模 p 比值 ĉ2 = Δ·x̂⁻¹（Δ = x_(q+1) − x_q 为输入历史的递推增量），
曲线分四个区域（h2 模型，q=4；h4 同构但平台更低）：

| 区域 | ĉ2 | 行为 |
|---|---|---|
| **盆地（规则 A）** | = 1 恰好 | **100% 按规则 A 算**（即残差 x_(q+1)−x_q−x̂ ≡ 0） |
| **盆地（规则 B）** | = 2 恰好 | **100% 按规则 B 算**（残差 x_(q+1)−x_q−2x̂ ≡ 0） |
| **肩区** | = 3 | 方向不对称：86% 倒向 B vs 13% 倒向 A（B 的盆地更宽） |
| **平台（远区）** | ≥ 4 | 不崩坏（neither≈0），按固定先验"抛硬币"：P(B)≈0.58 / P(A)≈0.40 |

[(1,1),(2,3)] 模型上复验：盆地出现在**完整形式**残差
x_(q+1)−2x_q−3x̂ = 0 处（c1=2 显式参与），否决了 c1=1 捷径假说——
模型学到的是通用的逐规则残差检验，不是简化公式。

模 p 空间的结构证据：ĉ2 = 126（≡−1）、125（≡−2）处出现弱化版肩部
（模环绕），ĉ2 = 64（≡2⁻¹）处有微弱扰动。

## 4. 一句话结论

> **模型在证据维度上实现了精确的逐规则残差归零检测器**：
> 某条规则的残差恰好为 0 → 按那条规则算（~99-100%）；
> 都不为 0 → 按固定先验选一条规则照算（输出仍合法），
> 先验偏向系数更大的规则（B 盆地更宽、平台更高）。

## 5. 此实验解释/连带的旧谜题

- **B3（翻转率天花板 ~0.65）**：自然 patch 的证据值几乎从不落在目标盆地
  （要求 x_(q-1)^A ≡ 2·x_(q-1)^B），观测翻转率 = 盆地命中 + 肩区/平台份额；
  理想证据处翻转率 99.6% → 天花板是证据值说服力，不是判定能力上限；
- **B2（方向不对称）**：判定函数本身不对称（肩区 86% vs 13%、平台
  0.58 vs 0.40），与规则泛化实验"b≥3 被吸入 b=2"自洽；
- **数值距离假说全灭的原因**：模型的度量在模 p 比值空间，不在数值距离空间。

## 6. 注意事项 / 边界

- 合成构造假设 **l1 结构**（被读位置的表示 = 纯 token embedding）；
  l2 模型需先在 layer-0 输出层面合成（待办）；
- 盆地捕获率（干预下鲁棒性）与自然准确率不可直接互换：大系数规则的
  捕获率衰退（1.00→0.87→0.80）在自然行为中只表现为 1~3 点的尾部差距；
- 远区行为逐模型不同：冷启动 N=3 模型抛软硬币，课程 N=3 模型 68% 崩坏；
- 残差检验的信息论边界：单三元组只能"检验"已知候选规则，不能"求解"
  未知系数（两个未知数需两个方程）。
