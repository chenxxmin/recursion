# 变体实验：同代数组系数 × 不定长+主体监督（2026-10-20）

## 背景

overnight_h123_p127_d512_600（600 run 普通 single 递推）的双分类分析显示：特征根类型（重根/λ=1/λ=−1/其他）与循环轨道结构（15 类）对收敛 epoch 的解释力都很弱（轨道长度与起跳 Spearman ρ=−0.02），且组内散布 ≥ 组间差异。本批实验把问题换到填空/纠错变体上：**双分类完全同组的系数，在变体任务下学习动力学是否仍有差异**。

选系数：最大双分类同组单元 **other ∩ split_{42,126}**（特征方程两根分裂、阶 42/126、周期 126）内 6 组，张满 overnight 起跳谱并含旧批重叠：

|---|---|---|
| [25,56] | 150.0（组内最快） | 旧 10coef 填空通过 |
| [62,59] | 153.8 | 旧 8coefB 填空失败 |
| [56,93] | 155.5 | 新 |
| [5,3] | 160.0 | 旧 10coef 填空通过 |
| [67,65] | 161.5 | 旧 8coefB 填空失败 |
| [44,59] | 174.2（组内最慢） | 新 |

## 批次 1：同组批（12 run）

配置：d512l2r8h4，P=127，ORDER=2，SEQ_LEN 5~10 不定长，BODY_SUPERVISION=true，TEST_ALL_POSITIONS（填空），POS_PROBE，seed42×1，EPOCHS 3000 / EVAL_INTERVAL 5 / MAX_TRAIN_HOURS 1.0 / SAVE_CHECKPOINTS=false。
JSON：`experiments/variant_o2_samecell_d512l2_P127_len5to10.json`；日志：`/data/cxm/recursion/variant_o2_samecell_d512l2_P127_len5to10/logs/`；图：`plots/variant_o2_samecell_len5to10_curves.png`。

### 填空：6/6 实质解决（含旧失败组 [62,59]、[67,65]）

- PosProbe 逐位置填空 acc 全部 ≈100%（唯一例外 a25b56 k01=88.3%）；起跳 epoch 375–975。
- overall test acc 整齐停在 95.6–96.0%，无一早停。**是指标天花板不是没学会**：主体监督把 x₂ 槽计入 acc，空白落在 x₀/x₁ 时（概率 2/L̄≈28%）该槽因果上不可推 → 恒 ~72%，恰好解释 1−2/L̄²≈95.8% 平台。
- 逐槽：x3~x9 全 1.00（空白在前缀时模型自发逆向填补 xₖ=(x_{k+2}−c·x_{k+1})·… 再正向续写），x2 槽贴不可约下限 0.73。

### 纠错：0/6 收敛，平台 77.6–86.5%

三成分拆分（末次 eval，PosProbe 256 固定探针窗）：

| 成分 | 加权总体 | 位置依赖 |
|---|---|---|
| 续写 body | ~92% | x2≈0.70（贴不可约下限）、x3≈0.62（**低于** ~86% 下限：污损值被直接当操作数）、x4/x5≈0.97、x7~x9 退化到 0.75–0.88 |
| 位置头 | 62.0% | 两端差中间好：k03 峰值 85–97%，k08/k09 崩塌（多数 <27%，末端右侧无上下文）；a62b59 例外（k09=78%，总体 79.3%）；a67b65 最差 31.5% |
| 值头 | 73.7% | k≥3 全 99–100%；k00–k02 逆向推断分化剧烈：a44b59=96/87/98，a5b3=1.2/0/29.7 |

所有 run best 在 ~2350–2520 epoch 后轻微回落（后期振荡）。

### 关键结论：组内差异任务依赖

overnight 起跳顺序（a25b56 最快 / a44b59 最慢）在填空里**完全反转**（a25b56 最慢 975 / a44b59 第 2 快 580）。同一代数组内系数的"难度"不是内在属性，是任务×系数交互；两类代数分类对学习动力学均无决定力。

## 批次 2：主体监督消融（4 run）

填空，旧失败组系数 [62,59]、[67,65]，2×2 补齐：
JSON：`experiments/variant_o2_ablation_bodysup_P127.json`；日志：`/data/cxm/recursion/variant_o2_ablation_bodysup_P127/logs/`。

| | 主体监督 ON | 主体监督 OFF |
|---|---|---|
| 定长 16 | ✅ 99.0%（@465 / @1055 早停） | ❌ 旧 8coefB：0/8（3000 epoch 不收敛） |
| 不定长 5~10 | ✅ ~96% 平台（探针 ~100%） | ❌ 4.5% / 0.9%（train 100% 纯背诵） |

**结论：主体监督是填空从失败到收敛的充分必要因素；不定长对可学性无影响。** 无主体监督时 train 100%/test<5% = 纯记忆；主体监督使记忆路线在主体槽位上不可行，迫使学规则电路。

### 附带：填空/纠错差异的机制解释

空白是词汇表外专用 token（检测免费），错误值是同分布合法值（检测需自发做一致性检验）。证据链：纠错值头被告知位置后 k≥3≈100%（检测免费时纠错≈填空），位置头 62% 是最短板；续写 x3 槽低于不可约下限说明污损值确实被当作合法操作数进入前向递推。此外填空的逆向填补电路在每条样本上都被强制训练，纠错里"信任输入"在大部分槽位可蒙对、纠错训练压力被稀释——这解释了两任务逆向推断能力的差距（填空 k0/k1≈100% vs 纠错 k0–k2 普遍崩）。
