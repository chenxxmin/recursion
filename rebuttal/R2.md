# Response to Reviewer 2

Thank you for your helpful comments.

**Regarding W1: Confounds in the inter/intra comparison.** **We focus on learning capability under the stated protocols and withdraw the attribution of the original difference to switching versus identification.** The four conditions are A: untagged fixed-rule sequences; A′: the same value sequences with uninformative NULL tokens in tag positions; B: fixed-rule sequences with repeated rule tags; and C: sequences with stepwise tags and potentially changing rules. The paired two-rule A/A′ control exceeds 99% in both conditions and both seeds. Tagged B and C both exceed 99% with ten rules in both available seeds.

Different data sizes reflect different sampling designs: fixed-rule examples have $Np^k$ generating configurations, allowing a fixed 70% initial-state allocation per rule; tagged switching sequences have $p^kN^{T-k}$ configurations, motivating a fixed sample of 300,000. This supports reporting learning capability within each protocol. It does not establish equal-budget efficiency or fully isolate switching, and unsuccessful runs indicate failure only within their executed budgets.

**Regarding W2: Trajectory splitting and higher-order sampling.** **The orbit split guarantees disjoint initial states, but the original claim of disjoint length-$k$ subsequences was too strong.** To retain exactly $\lfloor0.7p^k\rfloor$ training initial states, we split at most one orbit into contiguous portions. Prohibiting this can prevent the prescribed allocation, particularly when most nonzero states belong to one long orbit. Boundary-crossing windows were retained, allowing local overlap at both cyclic interfaces.

We reconstructed the clean single-rule baseline, $k=2$, $p=127$, $T=16$, rule $(1,1)$, using the historical generator. All three audited seeds (0, 17996, 18318) give the same counts:

| Audit quantity | Count |
|---|---:|
| Shared initial states | 0 |
| Shared distinct length-2 states | 28 |
| Shared distinct complete transitions | 26 |
| Test predictions involving a seen transition | 182 / 67,746 (0.269%) |

For any fixed model, this baseline's overall and unseen-transition accuracies differ by at most 0.269 percentage points. The [counts](../reports/static_overlap_20261110/results.json) include both cyclic interfaces.

For higher-order experiments using uniform initial-state sampling, the motivation is to distribute a limited training budget across the exponentially growing state space: contiguous orbit sampling can concentrate windows in a few segments with substantial local redundancy. Uniform sampling avoids requiring such contiguous selection. In the randomly sampled order-three experiment with rule $(1,2,2)$ and first-position weight 40, we verified a **99.33% conservative accuracy lower bound on unseen transitions**, using positions 4–16 of the last recorded fresh evaluation. This supports generalization beyond memorized local transitions; fresh sampling itself is not a disjointness guarantee.
