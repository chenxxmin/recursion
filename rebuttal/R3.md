# Response to Reviewer 3

Thank you for your helpful comments.

**Regarding W1: Motivation and definitions.** **Our setting isolates sequential state updates and rule selection that also arise in language understanding.** For example, “Alice holds a red ball and Bob a blue ball; they swap; Alice gives her ball to Carol” requires tracking intermediate states to determine who holds the red ball. Our recurrence tasks make such updates precisely controllable; they do not model the full complexity of language. Modular arithmetic provides a finite vocabulary, exact targets, and analytically testable alternative strategies. Appendix F already extends the experiments to nonlinear rules, although those tasks remain modular.

We have rewritten the definitions explicitly: $p$ is prime, $q_t,a_i\in\{0,\ldots,p-1\}$ are scalars, $\mathbf a=(a_1,\ldots,a_k)$ is a coefficient vector, and

$$q_t=\left(\sum_{i=1}^{k}a_iq_{t-i}\right)\bmod p,\qquad t=k+1,\ldots,T.$$

Here $a_1$ multiplies the most recent value, $f_{\mathbf a}$ maps the preceding $k$ values to the next value, and $\mathcal A$ is the pool of rule vectors. For $p=7$, $\mathbf a=(1,1)$ and initial values $1,2$, the sequence is $1,2,3,5,1,6,\ldots$. These definitions appear in the accompanying [revision text](manuscript_revision_text.md).

**Regarding W2: Low order and the order-four results.** **Recurrence order specifies the generating dependency, not the model's context limit or the complexity of language.** Unknown rule identity and missing values can require earlier context. We chose $p=127$ to permit practical order-two enumeration; higher-order spaces grow exponentially. Moreover, one two-layer, width-1024 run with $p=31$ and coefficients $(19,30,13,21)$ reaches 99.51% fresh-test accuracy. These coefficients admit no universal linear shortcut using fewer than four operands within lag 16. The [learning curve](../plots/order4_p31_no_shortcut_learning_curve.pdf) establishes a successful order-four configuration; it is not a controlled ablation of $p$ alone.

**Regarding W3: Sequence length and autoregressive evaluation.** **Training and the reported token-level learning curves already use causal masking and teacher forcing, as you suggest.** Earlier predictions are not fed back into subsequent inputs. We omitted the explicit length: ordinarily $T=16$ numerical values; order-two intra sequences add 14 rule tags, giving 30 tokens. The main masking experiments use numerical training length 64; masking replaces values rather than adding tokens. $T$ excludes rule tags, and longer evaluation windows are separate settings.

**Regarding W4: Algebraic shortcuts.** **Our shortcut uses fewer operands but requires a longer history, so it is not interchangeable with the original rule at every supervised position.** The recurrence $q_t=q_{t-1}+q_{t-2}+q_{t-3}$ implies $q_t=2q_{t-1}-q_{t-4}$ modulo $p$, but the latter cannot predict $q_4$, which is included in the loss. Thus “fewer operands” does not mean “lower order.” We use *algebraic shortcut* to describe this sparse, delayed formula and study when it is learned; we do not regard a valid alternative formula as intrinsically undesirable or equate it with a spurious correlation.

**Regarding W5: Significance.** **We address three questions about multi-rule sequential recurrence: when depth and width help, how masking changes prediction strategies, and how shortcut delay shapes learning.** The findings include task-dependent architectural responses, alternative prediction formulas that bypass missing values, and different learning dynamics across positions where a shortcut is or is not available. These contribute specific evidence and diagnostic methods to Transformer algorithmic learning. Empirical conclusions concern the tested recurrences; implications for natural language remain hypotheses.
