# Response to Reviewer 1

Thank you for your helpful comments.

**Regarding W1: Novelty and mechanistic insight.** **Our contribution is a quantitative account of how recurrence structure changes architectural responses and prediction strategies.** We vary order, rule count, and masking jointly. Masked two-rule inter-trajectory learning succeeds at width 1024 with six layers, whereas width 4096 with two layers does not succeed within the tested budget (Appendix E.2); widening also helps single-rule masked prediction (Section 3.2). Algebraically equivalent formulas let us test which historical values models use, how shortcut delay affects learning across positions, and how loss weighting changes this behavior. Probes provide complementary evidence about rule information. We do not claim novelty for the general benefits of scale or curriculum learning.

**Regarding W2: Inter- versus intra-trajectory learning.** **These settings represent two forms of multi-task sequence learning, and their original comparison cannot isolate rule identification from switching.** Inter abstracts adaptation to an implicit, persistent domain or style; intra abstracts successive explicit instructions, such as summarizing and then translating. We withdraw the causal attribution based on their direct comparison and introduce the following additional conditions:

| Condition | Rule within a sequence | Rule information |
|---|---|---|
| A | Fixed | No tag |
| A′ | Fixed | Uninformative NULL tokens in tag positions |
| B | Fixed | Repeated rule tag |
| C | May change | Current rule tag at each step |

In the paired two-rule format control, A and A′ both exceed 99% test accuracy in both seeds. Tagged B and C both exceed 99% with ten rules in both available seeds. These results characterize learning capability under the respective protocols; data, supervision, and training budgets are not fully matched across all four conditions, so they do not establish an isolated switching effect.

**Regarding W3: Why distinguish valid prediction rules?** **The shortcut has a longer history requirement and cannot cover all supervised positions.** For example, the three-term recurrence admits the two-term formula $q_t=2q_{t-1}-q_{t-4}$ modulo $p$, which applies from $q_5$ but cannot predict $q_4$. Our loss already supervises $q_4$, so learning only the shortcut leaves part of the task unsolved. We study the observed learning dynamics without asserting that the original formula is uniquely preferable. Likewise, Section 5.3 changes early history while preserving sufficient local information to distinguish dependence on the full trajectory from local rule application. This reveals information dependencies that ordinary prediction accuracy cannot distinguish.

**Regarding W4: Presentation.** **We have prepared a methods overview and a unified capability roadmap for the main text.** The overview explains formula fitting on randomized inputs, interventions testing local rule agreement, and probes measuring rule decodability. The roadmap consolidates the depth/width findings and connects Sections 3–5, with detailed derivations retained in the appendix. Both additions appear in the accompanying [revision text](manuscript_revision_text.md).
