# Overnight H1/H2/H3 - six GPU sweep

## Configuration

- 150 unique order-2 coefficient pairs at p=127, 4 seeds each, total 600 runs.
- H1: 8 groups of 8 pairs = 64 pairs / 256 runs.
- H2: 9 cycle families = 56 pairs / 224 runs.
- H3: 10 independent matched fixed-a triplets = 30 pairs / 120 runs.
- The complete 600-run manifest includes the exact original 220 jobs, unchanged.
- The additive 380-run manifest contains *only* missing jobs for existing or new coefficients.
- The 220-run original manifest remains untouched. Each manifest produces a distinct
  log/model directory when run through src/batch_run.py.
- Same d512 L2 H4, full_split 70/30, length16, 1000 epoch cap, 0.0833 hour per-job wall-clock cap,
  stop at 99% test accuracy. Concurrency is 6 for all-600 and 4 for additive-380.
- Selected coefficient pairs were verified to have no one-token shortcut at lag < 16.
- For H2 split-root families, the minimum one-token relation is always q_t=-q_(t-63).
- H3 matches a and the 127 dominant 126-cycles across root1, rootminus1, other.
  This is NOT exact global cycle matching. A further strict fixed-a triplet at a=111
  overlaps an existing H1 coefficient (111,112); it is intentionally not duplicated.
- H2 irreducible eigenroot orders are 384, 896, 5376, 16128, yielding strongly varying orbits.
  Beware full_split may split a giant orbit at the train/test boundary.

## If you have not started the 220-run experiment

```bash
BATCH_RUN_GPUS=0,1,2,3,4,5 BATCH_RUN_REQUIRE_GPU=1 \\
python src/batch_run.py experiments/overnight_h123_p127_d512_600.json \\
  --base-dir /data/cxm/recursion_results --model-base-dir /data/cxm/models
```

## If the original 220-run experiment is already running on GPUs 0 and 1

Run *only the additional 380 jobs* on GPUs 2-5:

```bash
BATCH_RUN_GPUS=2,3,4,5 BATCH_RUN_REQUIRE_GPU=1 \\
python src/batch_run.py experiments/overnight_h123_p127_d512_extra_380.json \\
  --base-dir /data/cxm/recursion_results --model-base-dir /data/cxm/models
```

This preserves the old training runs and keeps their logs and checkpoints separate.

## Log handling

Inspect return codes for each experiment; a five-minute timeout can result in a
resume checkpoint and must be counted as censored, not as a permanent failure.
On successful training, batch_run.py also runs an attention analysis; plan time
and disk space for this per-run postprocessing.
